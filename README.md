# Computer Science 7 - Las Positas Spring 2025

Completed as a dual enrollment student during my senior year in high school.

CS 7: Introduction to Computer Programming Concepts

Topics Covered:
- Problem-solving and algorithm design
- Variables, expressions, and data types
- User input and output
- Conditional statements and decision-making
- Loops and iteration
- Functions and modular programming
- Lists and arrays
- File input/output
- Object-oriented programming concepts
- Program testing and debugging

Course Description:
An introductory course in computer programming concepts and fundamental coding skills using object-oriented languages such as Python. 
The course covered problem-solving techniques, algorithm development, and common programming constructs including variables, expressions, input/output, decision-making, loops, and arrays.
These projects were completed as coursework and demonstrate the progression of my programming skills during my first college-level computer science course.
